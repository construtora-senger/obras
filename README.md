# Senger — Obras para Terceiros

Landing page estática recriada do zero para o portfólio de obras para terceiros da Construtora Senger.

## GitHub Pages
1. Envie **todo o conteúdo desta pasta** para a raiz do repositório `obrasterceirizadas`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Branch: `main` / pasta `/ (root)`.
4. Salve.

O site é HTML/CSS/JS puro e não exige build.
